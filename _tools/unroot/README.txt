Снятие root (KingRoot / SuperSU / RootMaster) с ГУ Geely Coolray / Belgee X50

Скрипт удаляет файлы root и возвращает подменённые системные файлы из бэкапов
самой магнитолы. Стоковых файлов с собой не несёт, чужих версий не ставит.

ВАЖНО: по умолчанию скрипт работает в режиме ПРОВЕРКИ (dry-run) и НИЧЕГО не меняет —
только пишет, что нашёл и что сделал бы. Это безопасно.

ШАГ 1. Проверка (ничего не меняется)
  1. Распакуйте архив в корень флешки (FAT32): в корне должны быть папка
     b832bc61... и файл unroot.sh.
  2. Вставьте флешку в USB при включённом зажигании, подождите 1-2 минуты, выньте.
  3. На флешке появится unroot_log.txt. Отправьте его в чат — по нему видно, что
     за root стоит и что скрипт собирается удалить/восстановить.

ШАГ 2. Реальная чистка (только после проверки лога)
  1. Создайте в корне флешки пустой файл с именем  doit  (без расширения).
  2. Снова вставьте флешку, подождите, выньте, прочитайте unroot_log.txt.
     В конце должно быть "[OK] root-файлы удалены".
  3. Перезагрузите ГУ (или заранее создайте в корне ещё файл  reboot  —
     тогда магнитола перезагрузится сама после чистки).

Если в логе "нужна БАЗОВАЯ перепрошивка" — значит подменён системный бинарник,
а его оригинала на машине нет: тогда только полная перепрошивка ГУ.

Скрипт только читает и чистит, прошивку не ставит.
