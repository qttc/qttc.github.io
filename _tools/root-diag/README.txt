Диагностика root на ГУ Geely Coolray / Belgee X50

Скрипт только собирает список файлов и ничего не меняет на магнитоле.

1. Распакуйте архив в корень флешки (FAT32): папка b832bc61... и файл root_diag.sh должны лежать в корне.
2. Вставьте флешку в USB при включённом зажигании, подождите 1-2 минуты.
3. Выньте флешку. На ней появится файл root_diag_log.txt - отправьте его в чат.

В конце лога должна быть строка "=== DONE". Если файла нет - напишите, в какой порт вставляли флешку.
