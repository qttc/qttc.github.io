# Как подготовить флешку для ГУ

Все пакеты для старого ГУ на Android 4.3 ставятся одинаково: архив распаковывают на флешку, флешку вставляют в машину, магнитола сама запускает скрипт. Правила ниже общие для [Community](/pages/community/), [отката и Last Chance](/pages/rollback/), [coorlay](/pages/carplay-no-dongle/) и [беспроводного Android Auto](/pages/wireless-android-auto/).

## Какая флешка нужна

| | Требование |
| --- | --- |
| Объём | 2–8 ГБ |
| Файловая система | FAT32 |
| Разметка | MBR |
| Содержимое | только один распакованный пакет |

Старые небольшие флешки обычно уже отформатированы так. Требования те же, что [для установки Community](/pages/community/#какая-флешка-нужна-для-установки-community).

## Как отформатировать в FAT32 в Windows

1. Скопируйте с флешки всё нужное: форматирование стирает её целиком.
2. «Этот компьютер» → правый клик по флешке → «Форматировать».
3. Файловая система — **FAT32**, размер кластера — по умолчанию, галка «Быстрое» — можно оставить.
4. «Начать» → «ОК».

## Как проверить и поменять разметку на MBR

**Проверить:** Win+X → «Управление дисками» → правый клик по флешке в нижней части окна (слева, надпись «Диск N») → «Свойства» → вкладка «Тома». В строке «Стиль раздела» должно быть «Основная загрузочная запись (MBR)».

**Если там GPT:** в «Управлении дисками» правый клик по разделу флешки → «Удалить том», затем правый клик по «Диск N» → «Преобразовать в MBR-диск». После этого правый клик по пустому месту → «Создать простой том» с файловой системой FAT32. Смотрите на размер диска и не перепутайте флешку с жёстким диском: удаление тома стирает данные.

## Как записать пакет на флешку

- **Один пакет — одна флешка.** Перед записью удалите с флешки всё старое. У всех пакетов общая папка запуска `b832bc61472727635baffcf25dd28e9f239273e2`, поэтому второй пакет перезапишет первый.
- **Сначала распакуйте архив** в отдельную папку на компьютере, потом скопируйте её **содержимое** в корень флешки.
- **Папка `b832bc61…` должна лежать прямо в корне**, а не внутри другой папки. Имя папки не меняйте: по нему ГУ находит скрипт.
- Безопасно извлеките флешку в Windows перед тем, как вынуть её из компьютера.

Порт — обычно любой USB в машине. Если в инструкции пакета указан конкретный разъём, используйте его.

## Частые вопросы

### Почему ГУ не видит флешку или ничего не происходит?

Проверьте по порядку: файловая система FAT32 и разметка MBR; папка `b832bc61…` лежит в корне и не переименована; архив распакован, а не скопирован как .zip; на флешке только один пакет. Если всё так — возьмите другую флешку, лучше небольшую и старую.

_[К оглавлению](#оглавление)_

### Подойдёт ли флешка на 16 или 32 ГБ?

Требование для пакетов Community — 2–8 ГБ, поэтому для прошивки и отката берите флешку в этих пределах.

_[К оглавлению](#оглавление)_

### Можно ли оставить на флешке музыку?

Лучше нет: держите для пакетов отдельную чистую флешку. Так скрипт точно найдёт свои файлы, а лог работы, который многие пакеты пишут в корень, не потеряется среди других.
