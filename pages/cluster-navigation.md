# Стрелки навигации на приборной панели Geely Coolray / Belgee X50

Подсказки навигатора — стрелку манёвра и расстояние до него — можно вывести на приборную панель, чтобы не смотреть на экран магнитолы. Для этого нужны две вещи: программная часть на головном устройстве и **кодировка самой приборки** сканером. Без кодировки стрелок не будет ни с какой прошивкой.

Инструкция для дорестайлинговых машин со старым ГУ на Android 4.3. Собрана по опыту владельцев из [Telegram-сообщества](https://t.me/CoolRay_Android_Develop) и Drive2.

## Как это работает

Стрелки берёт из **Яндекс Навигатора, установленного на самом ГУ**, системный сервис IPKServer и передаёт их на приборную панель. Сервис и виджет навигации на рабочем столе ставит прошивка [Community](/pages/community/) (файлы `KC2_IPKServer.apk`, `XCNaviService.apk`).

Приборка показывает подсказки, только если в её кодировке включена эта функция. С завода она выключена.

| Источник навигации | Стрелки на приборке |
| --- | --- |
| Яндекс Навигатор на ГУ | да, когда навигатор свёрнут |
| CarPlay через [coorlay](/pages/carplay-no-dongle/) | да, если приборка закодирована |
| CarPlay / Android Auto через донгл [Carlinkit](/pages/carlinkit/) (AutoKit) | нет |
| Android Auto через HUR / OHU | нет |

## Что понадобится

1. **Community Full** на ГУ — в ней есть сервис IPKServer. В облегчённых пакетах для Android Auto и CarPlay кнопка навигации в нижней панели открывает HUR или AutoKit, а не навигатор.
2. **Яндекс Навигатор на ГУ** — как установить, на странице [Приложения для ГУ](/pages/apps/#установка-навигатора-на-гу).
3. **Нормальный GPS.** Без GPS-приёмника ГУ знает положение только по сети, и маршрут может не определиться. Владельцы ставят USB-приёмник на чипе u-blox.
4. **Кодировка приборки** — сканер Launch с пакетом Geely Customize (на 4PDA пишут, что нужна версия от 23.42). Своего сканера нет — ищите сервис, который прошивает магнитолы: по отчётам владельцев работа занимает пару минут.

## Кодировка приборки

В кодировке блока приборной панели меняют **один байт**. Пример из [отчёта на Drive2](https://www.drive2.ru/l/649247048746418118/) — `5E` меняется на `3F`:

```
было:  0E045401126952028011835E00000000
стало: 0E045401126952028011833F00000000
```

Отличаются только символы 23–24 — двенадцатый байт кодировки.

- Код у каждой машины свой — **не переписывайте строку из примера целиком**, меняйте только этот байт в своей.
- Перед изменением сохраните исходную кодировку, чтобы можно было вернуть.
- Пример относится к цифровой приборке. Для аналоговой код другой — разбор в [теме ГУ Geely Coolray на 4PDA](https://4pda.to/forum/index.php?showtopic=1001500&view=findpost&p=109806958).

## Если стрелки не появляются

Частый случай — приборка закодирована, Community и навигатор стоят, а на приборке пишет **«маршрут не определён»**. Что проверить по порядку:

1. **Сверните навигатор.** Стрелки появляются на приборке, только когда Яндекс Навигатор свёрнут, а не открыт на весь экран.
2. **Перевыдайте уведомления.** В настройках Android откройте приложение Яндекс Навигатор, выключите и снова включите уведомления. Затем запустите навигатор, постройте маршрут и сверните его.
3. **Разрешите работу в фоне** — в расширенных настройках навигатора, с маршрутом и без.
4. **Проверьте GPS** — без точных координат маршрут может не определиться.
5. **ГУ H50: откатите IPKServer.** Сервис из Community на части ГУ H50 не работает — у этого блока другое железо. Помогает вернуть стоковый сервис архивом «Откат IPKServer.zip», остальное от Community остаётся. Архив — в разделе [Частичный откат](/pages/rollback/#частичный-откат).

**Подсказки на английском.** Переключите язык приборки на английский и обратно на русский, затем перезагрузите магнитолу.

**Мелкие съезды не видно.** На приборке показываются крупные повороты и развязки; съезды на дублёр, по отчётам владельцев, могут не отображаться.

## Частые вопросы

### Появятся ли стрелки после установки Community?

Нет. Community ставит сервис, который передаёт подсказки, но приборку нужно отдельно закодировать сканером. Без кодировки стрелок не будет.

### Будут ли стрелки с CarPlay или Android Auto?

С CarPlay через бесплатное приложение [coorlay](/pages/carplay-no-dongle/) — да, если приборка закодирована. Через донгл Carlinkit и через Android Auto (HUR, OHU) — нет: стрелки работают с Яндекс Навигатором на самом ГУ.

### Почему на приборке «маршрут не определён»?

Чаще всего навигатор не свёрнут, у него нет разрешения на уведомления или работу в фоне, либо ГУ не получает точные координаты. На ГУ H50 причиной бывает сервис IPKServer из Community — его откатывают на стоковый. Подробно — в разделе [Если стрелки не появляются](#если-стрелки-не-появляются).

### Чем закодировать приборку?

Сканером Launch с пакетом Geely Customize. По опыту владельцев, простые OBD-адаптеры для этого не подходят.
