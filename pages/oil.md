# Масло, антифриз и тормозная жидкость Geely Coolray / Belgee X50

Какое масло заливать в двигатель и в роботизированную коробку (DCT), какой антифриз и тормозную жидкость, сколько их нужно и как часто менять — по данным Geely. Плюс масла, которые владельцы уже проверили, с артикулами для заказа.

Объёмы и интервалы — из руководства по эксплуатации и карты ТО Geely для Coolray SX11.

## Масло в двигатель: допуски и объём

| Параметр | Значение |
| --- | --- |
| Вязкость | **0W-20** |
| Класс | API SP, ACEA C5 |
| Допуск | VCC RBS0-2AE |
| Двигатель | JLH-3G15TD |
| Объём при замене | **5,6 ± 0,1 л** (сухой двигатель — 6,6 л) |
| Замена масла и фильтра | каждые **10 000 км**, первая — на ТО-0 (3 000 км) |
| Рекомендация Geely | Lopal 1 Advanced Fully Synthetic Series SP 0W-20 |

Подходит масло 0W-20 с этими допусками — ниже список проверенных владельцами.

## Антифриз (охлаждающая жидкость): тип и объём

| Параметр | Значение |
| --- | --- |
| Тип | охлаждающая жидкость на основе этиленгликоля, одобренная Geely |
| Заправочный объём | **6,5 л** |
| Замена | каждые **40 000 км или 2 года** |
| Оригинал Geely (концентрат) | LPAFRZ01L |
| Если оригинала нет | G12 / G12+ |

Антифриз Geely продаётся концентратом — перед заливкой его разводят водой.
