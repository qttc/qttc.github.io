## Масло в двигатель: допуски и объём

| Параметр | Значение |
| --- | --- |
| Вязкость | **0W-20** |
| Класс | API SP, ACEA C5 |
| Допуск | VCC RBS0-2AE |
| Объём при замене | **5,6 ± 0,1 л** |
| Рекомендация Geely | Lopal 1 Advanced Fully Synthetic Series SP 0W-20 |

Подходит масло 0W-20 с этими допусками — ниже список проверенных владельцами.
